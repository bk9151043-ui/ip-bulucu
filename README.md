# IP Bulucu

Bu proje, Python kullanılarak geliştirilmiş bir IP adresi analiz aracıdır.

## Nasıl Çalışır?

1. Hedef Belirleme: Kullanıcı, taranmasını istediği hedef IP adresini veya alan adını sisteme girer.
2. Sorgulama ve Analiz: Betik, arka planda gerekli ağ isteklerini gerçekleştirerek hedef hakkında bilgi toplar.
3. Sonuç Raporlama: Elde edilen verileri terminal ekranına anlaşılır ve düzenli bir şekilde yazdırır.

## Kurulum ve Kullanım

git clone https://github.com/bk9151043-ui/ip-bulucu.git
cd ip-bulucu
python3 ipbulucu.py
